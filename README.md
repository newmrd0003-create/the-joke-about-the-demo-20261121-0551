## About

This entry is a one-line joke about the most familiar moment of working beside an AI coding agent: the live demo. The agent rehearses all night, then crashes on the very first click — in the exact spot the developer told it never to touch. It is a joke every developer who has demoed agent-written code recognises at once, and the punchline lands on the one place that was supposed to be safe.
